# EDITOR KILO
Esse é um projeto feito com base no tutorial https://viewsourcecode.org/snaptoken/kilo/index.html

É um editor de texto simples de terminal feito para rodar no linux primariamente mas também roda em terminais que possam emular sistemas unix.

Pretendo assim que acabar o tutorial implementar minhas próprias funcionalidades para adequar ele ao meu workflow.

Conclui todas as operações básicas que fazem o editor ser funcional.
