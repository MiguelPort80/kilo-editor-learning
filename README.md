# EDITOR KILO
Esse é um projeto feito com base no tutorial https://viewsourcecode.org/snaptoken/kilo/index.html

É um editor de texto simples de terminal feito para rodar no linux primariamente mas também roda em terminais que possam emular sistemas unix.

Conclui todas as operações básicas que fazem o editor ser funcional. 

Adicionei os vim motions básicos de navegação(h/j/k/l).

## Requisitos
- Um sistema compatível com POSIX (Linux, macOS)
- Compilador C (como `gcc`)
- Ferramenta `make`

## Como Compilar e Executar
1. Clone o repositório:

```bash
    git clone https://github.com/MiguelPort80/kilo-editor-learning.git
```

2. Compile o projeto usando o make:
```bash
    make
```
3. Execute passando o arquivo que deseja editar, ou execute sem nenhum arquivo para criar um novo:

```bash
    ./kilo <seu_arquivo>
```
